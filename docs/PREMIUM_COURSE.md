# 유료 핵심 콘텐츠: 승급 과정 · 내 대국 코치 · 나의 체스 공방

작성: 2026-11-08 · 빌드 `2026.11.08.3`

사용자 요청(2026-11-08): "제안 순서대로 진행해줘. 그리고 내 대국 코치도 추가하고 꾸미기 기능을 개선하거나 완전히 새로운 형태로 만들어줘. … 실제 배포시에는 인앱으로 감쌀것이고, 서버비용이 최소로 드는 방향으로 일부 서버 자원을 활용할 수는 있어."

앞선 제안(같은 날): 유료 핵심은 무료 체스 수업의 다음 단계인 **승급 과정**이다. 기존 무료 기능은 잠그지 않는다. 결제는 앱(인앱 결제)으로 감쌀 때 붙인다.

상태 구분: **구현 완료 · 자동 검증 완료 · 공개 웹 배포(미리보기, 결제 없음) · 실제 결제 연결 없음 · 체스 지도자 검수 없음 · 실제 사용자 관찰 없음**.

## 1. 무엇이 무료이고 무엇이 유료인가

| 구분 | 무료 | 유료(앱에서 한 번 구매) |
|---|---|---|
| 기존 기능 | 체스 수업 15주제 225판·무한 연습, 대전, 놀이터, 모험, 기사의 여행, 프로필·백업 | 없음(잠그지 않음) |
| 승급 과정 | 단계마다 첫 주제 15판 전체, 다른 주제는 처음 3판(첫걸음) | 단계별 나머지 판·무한 연습·승급 시험·수료증·실전 승급전 |
| 내 대국 코치 | 대국마다 가장 중요한 장면 1개, 최근 대국 1판 | 장면 모두(최대 3개), 지난 대국 20판 |
| 꾸미기(공방) | 전부 무료. 별과 배움 기록으로 연다 | 없음(아이 대상 꾸미기 소액 결제는 하지 않음) |

상품(`js/store.js` `STORE_PRODUCTS`): `course_all`(전체), `course_stage1~3`(단계별), `coach_full`(코치). 가격은 앱 스토어가 정한다(이전 제안의 가설: 단계별 6,900원, 전체 14,900~19,900원 — 검증 전 값).

웹(현재 공개 주소)은 **미리보기**다. 결제가 없고 모든 콘텐츠가 열려 있다. 보호자 화면(프로필 · 설정 → 보호자)에서 곱셈 확인 뒤 **앱 잠금 미리보기**를 켜면 앱에서 잠기는 모습 그대로 볼 수 있다(주소 끝에 `?store=locked`를 붙여도 같다).

## 2. 승급 과정

3단계 × 4주제 × 15판(5단계 × 3판) = 180판. 화면 틀(목표·설명 칸, 같은 크기의 판, 버튼 두 개)은 체스 수업과 같다. 나는 흰색.

| 단계 | 주제 | 방식 | 판정(끝까지 계산) |
|---|---|---|---|
| 1. 두 수로 이기기 | 체크로 몰아 메이트(무료) · 길을 막고 메이트 · 내주고 메이트 | 내 수 → 상대 응수 → 내 수 | 첫 수 뒤 상대의 **모든** 응수에 한 수 메이트가 남아야 성공. 아니면 상대가 실제로 빠져나가는 수를 둔다 |
| | 두 수로 말 얻기 | 같음 | 첫 수: 상대의 모든 응수 뒤 내 가장 좋은 잡기(잡고 잡히기 3수)가 2점 이상(수업의 전술 판정과 같은 계산). 둘째 수: 실제 득실 2점 이상 |
| 2. 끝내기 달인 | 퀸으로 메이트(무료) · 룩으로 메이트 · 폰을 퀸으로 | 제한 수 안에서 계속 | **가능한 모든 국면을 미리 계산한 표**(퀸·룩: 메이트까지 거리, 폰: 승격까지 거리). 상대는 가장 오래 버티는 수를 둔다. 스테일메이트·말 잃기·비기는 판·제한 수 초과는 실패 |
| | 두 룩 사다리 메이트 | 같음 | 결과로 판정(메이트=성공). 제한 수는 생성할 때 예시 풀이로 실제 끝낸 수 + 여유 |
| 3. 첫 수부터 잘 두기 | 가운데 차지하기(무료) · 작은 말 꺼내기 · 캐슬링으로 킹 지키기 · 초반 함정 막기 | 한 수(캐슬링 포함) | 원칙 판정 + 안전 판정(상대가 이득 보고 잡을 내 말·한 수 메이트가 없어야). 함정 판은 상대가 실제로 메이트한다 |

- 끝내기 계산표: `js/course-rules.js` `crBuildKXK`, `crBuildKPK`. 앱에서 처음 쓸 때 만든다(데스크톱 Node 기준 표 하나 50~60ms). 검사로 확인한 값: 퀸 메이트 최대 10수, 룩 메이트 최대 16수, 폰 끝내기의 대치·가장자리 폰 비김.
- 두 수 메이트 탐색은 대전 AI의 빠른 수 생성기(`aiGenMoves`)를 그대로 쓴다. 승격은 퀸으로만 센다(체스 수업과 같은 규칙).
- 판 생성: `js/course-gen.js`(규칙) → `scripts/generate-course-levels.cjs`(고정 시드로 15판 고르기, `npm run generate:course`) → `js/course-levels.js`. 무한 연습과 승급 시험은 같은 생성기를 새 시드로 돌리고, 저장된 판은 열 때 같은 검사기로 다시 확인한다.
- 힌트: 정답 수를 알려 주지 않는다. 두 수 메이트=상대 킹이 갈 수 있는 칸, 두 수로 말 얻기=지켜진 상대 말과 지키는 말, 끝내기=상대 킹의 '상자', 폰=열쇠 칸, 초반=가운데 네 칸·집에 있는 작은 말·함정 화살표. 두 번 해본 뒤에 열린다(끝내기는 처음부터). 힌트로 푼 판은 💡.
- 끝내기에서 실패하면 **한 수 전으로** 돌아갈 수 있다. 수마다 "가장 빠른 길이에요 / 더 빨리 몰아붙이는 수도 있었어요"와 메이트(승격)까지 최소 수·남은 수를 보여 준다.
- 승급 시험: 단계의 네 주제에서 처음 보는 판(1·3단계 5판, 2단계 4판), 판마다 한 번, 힌트 없음. 한 판까지 틀려도 통과. 통과하면 수료증(이름·날짜·주제, 이미지 저장). **수료증은 앱 안의 기록이며 공인 급수가 아니라고 수료증에 적었다.**
- 실전 승급전: 처음 배치에서 컴퓨터(1단계 3단계 상대, 2단계 4단계, 3단계 5단계)와 표준 체스. 이기면 수료증에 '실전 승리'.
- 저장: 하던 판은 세션(형식 7)으로 저장하고, 복원할 때 교재와 기록된 수로 다시 만든다(파일 속 결과를 믿지 않음). 기록 `course_progress_v1`. 프로필 파일은 승급 과정 판·실전 승급전 저장이 들어 있을 때만 형식 7이다(과정·코치·공방 기록만 있으면 예전 형식 그대로라 예전 앱도 읽는다). 새 앱은 새 기록을 가져올 때 모두 검사한다.

## 3. 내 대국 코치

- 컴퓨터와 둔 판(나 = 흰색)의 수를 짧게 기록한다(`state.play.record`, 끝나면 `game_records_v1`에 최근 20판).
- 끝난 대국을 처음부터 다시 두며 내 수마다 살핀다(`coachInspect`): 상대에게 메이트 기회를 줌 → 이기던 판을 스테일메이트 → 한 수 메이트를 놓침 → 말을 공짜로 줌(잡고 잡히기 결과 3점 이상 손해) → 공짜 말을 놓침 → 포크·핀·꼬치·발견 공격을 놓침(수업의 전술 계산 3점 이상). 중요한 순서로 3개, 잘한 수 1개.
- 장면에서 다시 두기: 같은 판정으로 성공/실패, 실패하면 상대가 실제로 응수, '원래 둔 수' 화살표와 그 뒤 상대의 실제 수, 같은 주제 체스 수업의 무한 연습으로 연결.
- 들어가는 곳: 대전 결과 창과 끝난 판 아래의 "코치와 이 대국 다시 보기", 대전 설정 화면의 "내 대국 코치".
- 한계: 엔진 점수나 정확도는 보여 주지 않는다. 판정은 '내 한 수 + 상대 응수 + 잡고 잡히기' 범위라 깊은 전략 실수는 찾지 않는다.

## 4. 나의 체스 공방(꾸미기 새 형태)

- 홈의 🎨 꾸미기 → 공방. 위에 지금 꾸민 체스 세트 미리보기(작은 판·이름표·칭호), 아래 탭 네 개: **말 · 판 · 효과 · 칭호**.
- 판 색 6가지(나무·잔디·바다·사탕·밤하늘·대리석)는 별로 연다. 앱의 모든 체스판 색이 바뀐다.
- 성공 효과 5가지(색종이·별똥별·하트·비눗방울·불꽃놀이), 칭호 9가지(새싹 기사 … 두 수 박사·끝내기 달인·초반 박사·승급 과정 졸업)는 배움 기록으로 연다(수업 완료, 첫 승리, 과정 판, 코치 장면, 승급 시험).
- 고른 칭호는 홈 제목 아래에 보인다. 새로 열린 꾸미기는 홈에서 한 번 알려 준다.
- **다른 회사 캐릭터·상표 스킨(헬로카봇·티니핑·배달의민족)은 앱(인앱 결제) 판에서는 보이지 않게 했다.** 웹 미리보기에서는 그대로다. 앱 출시 전에 권리를 확인하거나 자체 디자인으로 바꿔야 한다(`docs/DEFERRED_RELEASE_READINESS.md`).

## 5. 앱으로 감쌀 때 연결할 것(결제)

웹 코드는 `window.ChessKidsStore`가 있으면 앱 모드로 바뀐다. 앱(Capacitor 등) 쪽에서 아래 네 함수를 제공하면 된다.

```js
window.ChessKidsStore = {
  getProducts: () => Promise.resolve([{ id: 'course_all', price: '₩19,900' }, /* … */]),
  getOwned:    () => Promise.resolve(['course_stage1']),           // 이미 산 상품 ID
  purchase:    id => Promise.resolve({ owned: ['course_stage1', id] }),
  restore:     () => Promise.resolve({ owned: [/* 스토어 기록 */] }),
};
```

- 서버 비용을 최소로: 영수증 검증을 직접 서버로 하지 않고 RevenueCat 같은 인앱 결제 서비스(일정 매출 이하 무료)를 쓰는 것을 추천한다. 구매 기록은 스토어 계정에 남으므로 기기를 바꿔도 복원된다.
- 구매·복원은 보호자 확인(곱셈) 뒤에만 열린다. 잠긴 콘텐츠를 아이가 누르면 결제 버튼 대신 "보호자에게 보여 주기" 안내가 나온다.
- 구매 권한은 기기 전역 저장(`chess_store_owned_v1`)이며 프로필 파일에 넣지 않는다.
- 정적 앱이라 코드를 고치면 잠금을 풀 수 있다. 아이용 일회성 콘텐츠로는 감수할 수준이라고 판단했다(더 강한 보호는 판 데이터를 서버에서 받는 구조가 필요).
