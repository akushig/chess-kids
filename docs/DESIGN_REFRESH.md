# 어린이체스 디자인 개편

2026-11-22. 아동용의 친근함을 유지하면서 체스 클럽 같은 차분한 인상을 만들고, 한 화면에 나열되던 선택지를 목적별로 묶었다. 체스 규칙·콘텐츠·결제 권한·프로필 저장 형식은 바꾸지 않았다.

## 화면과 메뉴

- **홈:** 체스 대전 시작, 배우기, 놀이터가 중심이다. 기사의 여행은 바로 가기로 제공한다. 공방·기록·프로필 설정과 모든 이어하기 기능을 유지했다.
- **배우기:** 처음 배우기 → 체스 수업 → 승급 과정을 하나의 화면에 모았다. 모험 지도에서 원하는 말을 고르거나 내 대국 코치로 이동할 수 있다. 수업·승급 화면에서 배우기로 돌아온다.
- **놀이터:** 탐험과 발견, 새로운 도전, 길찾기, 잡기와 안전, 대전 놀이 중 한 종류를 고른다. 기존 미니게임 8종과 원정대·팀 체스·승부의 한 장면을 모두 보존했다. 놀이를 마치고 돌아오면 고르던 종류를 유지한다.
- **대전:** 상대와 난이도, 시작 버튼이 먼저 보인다. 판 설정, 배운 말로 첫 대전, 다른 대전 방식은 각각 펼친다. 옵션 변경 후에도 설정 패널을 열어 둔다.
- **수업:** 5단원을 한 번에 하나씩 본다. 각 주제의 시작·이어하기, 판 고르기, 무한 연습을 유지했다.

## 시각 체계

`css/design.css`는 기존 게임별 보드 규칙 위에 적용하는 공통 디자인 계층이다. `js/app-design.js`는 동일한 24px 좌표계·선 굵기를 사용하는 메뉴 아이콘, 공통 탐색 메뉴, 배우기 화면을 제공한다.

배경은 옅은 회녹색, 주요 행동은 짙은 초록, 강조는 따뜻한 노랑이다. 과도한 그라데이션·입체 버튼·굵은 그림자를 줄이고 제목·본문·보조 설명의 대비와 여백으로 위계를 만들었다. 체스판 색과 기물 스킨은 공방의 선택을 그대로 따른다.

홈 일러스트는 이미 생성되어 있던 `icons/skins/royal-classic/atlas.webp`를 재사용한다. 추가 이미지 생성이나 API 호출은 하지 않았다. 큰 일러스트나 캐릭터는 생성 이미지를 사용하면 개성을 줄 수 있다. 작은 기능 아이콘은 일관된 벡터가 적합하며, 제목·버튼·설명은 이미지에 넣지 않고 HTML 텍스트로 유지한다.

## 텍스트와 작은 화면

메뉴 제목의 한 줄 고정과 설명의 두 줄 제한을 해제했다. 가로 배치의 텍스트 열에는 `min-width:0`, 긴 문자열에는 비상 줄바꿈, 한국어 문장에는 어절 단위 줄바꿈을 적용한다. 카드는 내용에 맞춰 늘어난다. 모바일에서는 프로필 이름을 접근성 이름에 유지하면서 아바타로 표시한다. 데스크톱의 긴 프로필 이름은 줄바꿈한다.

진행 중인 보드는 기존 고정 위치 계약을 보존한다. 장문의 게임 피드백은 기존 알림·스크롤 영역을 사용한다. SVG는 아이콘·기물 표현에 사용하며, 일반 UI 텍스트를 SVG 내부에 배치하지 않는다.

## 검증

- `npm test`: 규칙·콘텐츠·세션·프로필·오프라인 자산 검사.
- `node tests/layout-browser.cjs`: 이동·힌트·체크·결과·장문 피드백 동안 보드 위치를 유지하는 156개 시나리오.
- `npm run test:design`: 320·360·390·768·1280px에서 실제 메뉴 클릭, 모든 미니게임의 접근 경로, 이어하기와 되돌리기 보존, 옵션 패널 유지, 긴 프로필 이름, 글자 150% 확대, 버튼 밖으로 나가는 텍스트 검사.
- 기존 브라우저 검사도 새로운 진입 경로와 접힌 설정을 실제로 클릭하도록 갱신했다.

검수 이미지와 세부 결과는 기본 `/tmp/chess-design-qa`에 저장한다. 대표 화면은 [검수 폴더](qa/design-refresh/)에 보존한다. 실제 어린이의 메뉴 이해도는 플레이테스트가 추가로 필요하다.
