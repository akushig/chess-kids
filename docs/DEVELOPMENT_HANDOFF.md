## 2. 첫 위임 범위: A만 구현

### A-1. 원하는 활동에 바로 들어가기

- 홈의 주 진입을 `체스 대전 / 기사의 여행 · 나이트 투어 / 체스 처음 배우기`로 정리한다.
- 다른 기존 미니게임은 `전체 놀이` 같은 보조 진입으로 계속 제공한다. 삭제·유료화하지 않는다.
- 전역 이어하기 카드와 종류별 저장판을 유지한다. 나이트 입구는 저장판이 있으면 이어가며, 없으면 기존 목표 선택·조작 화면으로 들어간다. 체스 학습을 먼저 요구하지 않는다.
- 대전 입구에서는 하던 판, 컴퓨터와 새 판, 같은 기기에서 함께 두기를 찾을 수 있어야 한다. 새 판이 실제로 시작되기 전까지 기존 저장판을 교체하지 않는다.
- 현재 앱 이름/브랜드 전체 교체, 나이별 화면 분리, 새 온보딩 과정은 범위에 넣지 않는다.

완료 기준:
- 신규 사용자도 주 메뉴 한 번으로 대전 설정/나이트 플레이/입문으로 들어간다.
- 각 종류의 저장판으로 재진입해도 판·이동 수·설정·undo가 동일하다.
- 함께 두기를 온라인 대전으로 표시하지 않는다. 기존 다른 놀이도 접근 가능하다.

### A-2. 대전의 자연스러운 재도전

- 대국 종료 후 `같은 상대와 다시 두기`를 제공한다.
- 현재 대국의 실제 설정(mode, level, levelVersion, help, small, timer, face, autoMove)을 기준으로 새 판을 만든다. 단순히 현재 전역 설정을 읽으면 저장판을 복원한 뒤 다른 설정으로 재대결할 수 있으므로 주의한다.
- AI 대전에서 사람이 승리한 경우 선택 가능한 `다음 단계 도전`을 제공한다. 레벨 10에서는 범위를 넘는 버튼을 만들지 않는다.
- 무승부/패배/사람끼리 대전에서는 자동 레벨 변경을 하지 않는다. 사용자는 같은 상대 재대결이나 설정 변경을 고를 수 있다.
- 대국 중 새 판을 고르면 기존 교체 확인을 유지한다. 완료 후에는 불필요한 교체 확인을 추가하지 않는다.
- 새 대국은 정상 초기 배치/선택 없음/undo 없음/새 전체 제한 시간으로 시작한다. 종료한 판의 타이머·AI 콜백이 새 판을 건드리지 않아야 한다.
- 대국 중 몰래 강도를 바꾸는 적응형 AI, Elo 추정, 추가 AI 단계·강도 조정은 이번 범위가 아니다.

완료 기준:
- 저장판 복원 후 재대결, 친구 대전, 짧은 판, 제한 시간, AI 최상 단계에서 설정 보존이 확인된다.
- 다음 단계는 눌렀을 때만 한 단계 높아지고 나머지 설정은 유지된다.
- 체크/캐슬링/승격/종료 안내와 AI·시계 정지/재개가 그대로 동작한다.
- 진행 중 보드 좌표가 안내/결과/컨트롤 때문에 이동하지 않는다.

### A의 종료점

A-1/A-2 구현·검증·단계별 커밋 후 변경 내용, 검증 결과와 남은 관찰 과제를 보고한다. 사용자의 실제 반응을 확보한 것처럼 말하지 않는다. B/C의 제품 개발까지 자동으로 확장하지 않는다.

## 3. 다음 위임 후보: B 나이트 신규 규칙 10판 시험판

이 절은 후속 작업 정의다. 사용자가 B를 작업 범위에 포함했을 때 구현한다.

- 새로운 규칙은 `일부 칸이 없는 모양의 판`, `순서대로 지나야 하는 표식` 두 가지로 제한한다.
- 최초 10판은 규칙별 5판. 각 묶음은 첫 이해 1판, 응용 2판, 깊은 도전 2판을 목표로 편집한다. 체감 난이도는 관찰 후 조정할 가설이며 숫자만 붙여 확정하지 않는다.
- 초기 판에서는 두 제약을 동시에 도입하지 않는다. 시간 제한·복수 기물·사라지는 칸·온라인 순위표는 제외한다.
- 고정 ID/콘텐츠 버전/크기/시작/사용 가능한 칸/표식 순서/검증용 해법/기획 의도를 명세한다. 해법은 테스트용 증거이며 플레이어가 따라야 하는 단 하나의 정답이 아니다.
- 유효 칸 전체를 한 번씩 방문하면 성공이다. 순서 표식은 정해진 순서로 방문해야 하며, 사용 불가 칸에 착지할 수 없다.
- 사용 불가 칸과 이미 방문한 칸을 데이터와 UI에서 혼동하지 않는다. 나이트는 중간 칸을 뛰어넘으므로 사용 불가 칸을 일반 기물의 벽처럼 처리하지 않는다.
- 새로운 제약을 적용하는 이동/완료/힌트/갈림길 검사에는 같은 규칙 정의를 사용한다. 전체 경로와 갈림길 도움은 새 판에서도 제공한다.
- 검색 시간 초과와 해법 없음은 구분한다. 예산이 끝났다고 막힌 길로 표시하지 않는다.
- 기존 자유 투어·5×5~7×7·무작위 시작·산책·탐험·전체 경로·가족 같은 판은 그대로 유지한다.
- 새 판의 저장/복원/undo/프로필 내보내기·가져오기를 포함한다. 새 규칙을 모르는 예전 앱이 이를 일반 투어로 잘못 불러오지 않도록 백업 버전 호환을 설계한다. 기존 v1 파일은 계속 읽어야 한다.
- 시험판은 테스트 사용을 위해 무료로 제공한다. 결제 UI·가짜 구매 버튼·광고·구독을 넣지 않는다.

B 완료 기준:
- 10판 모두 콘텐츠 명세와 유효 해법이 있고 실제 입력으로 완료 가능.
- 시작/중간/완료/막힘/되돌리기에서 안내·카운터·판정이 일치.
- 대체 해법을 허용하고, 불가능한 이동과 잘못된 표식 순서를 설명.
- 저장과 파일 이동을 거쳐도 같은 문제·규칙·현재 위치·undo 유지.
- 콘텐츠 선택→플레이→완료→다음 판의 흐름이 작은 화면과 키보드에서도 가능.
- 사용자 관찰용 짧은 과제와 관찰 기록 양식을 작성. 코드 검사 통과를 재미/구매 수요 검증으로 간주하지 않음.

## 5. 변경하면 안 되는 제품 계약

- 이미 제공한 모든 기능은 무료 유지. 도움·갈림길·전체 경로·백업·프로필 수에 제한을 새로 만들지 않는다.
- 모든 프로필의 기능과 신규 기본값은 동일하다. child/adult 등의 내부 레거시 ID로 동작을 다르게 하지 않는다.
- 기존 프로필, 별, 꾸미기, 저장판, undo와 백업 v1의 호환을 보존한다.
- 메뉴 재진입으로 하던 판을 초기화하지 않는다. 명시적인 교체 선택 전에는 저장판을 덮어쓰지 않는다.
- 진행 중 보드는 고정한다. 새 안내 문단을 위에 삽입해 밀어내지 않는다.
- 기존 규칙 설명과 초보자의 막힘 복구를 훼손하지 않는다.
- 현재 미추적 `icons/skins/`는 기존 사용자 자산이다. 수정·스테이징하지 않는다. 작업 시작 시 Git 상태를 다시 확인한다.
- 새 서버·계정·분석 SDK·새 의존성 도입은 A/B의 기본 전제가 아니다. 필요해지면 근거와 변경 범위를 문서에 먼저 정리한다.

## 7. 검증과 작업 보고

시작할 때 현재 `package.json`, 테스트와 Git 상태를 읽는다. 작성 시점 기준 단위 검사는 78개이며 수가 늘 수 있다.

- `npm test`
- `npm run dev`로 로컬 서버 `127.0.0.1:8765` 실행.
- `CHESS_BROWSER_EXECUTABLE=<로컬 Chromium> npm run test:browser`
- 환경에 브라우저가 없다면 설치/실행 가능 경로를 확인하고 실제로 실행하지 못한 검사를 통과했다고 쓰지 않는다.

- 360×780/768×1024/1280×900에서 주요 흐름과 보드 위치·모달 초점·화면 넘침을 확인한다. 기존 나이트·프로필·체크/캐슬링 회귀를 유지한다.

변경 목적별로 커밋하고, 인수인계 문서에 변경 파일·검증 명령/결과·남은 관찰을 갱신한다. 마지막 보고에서는 구현 완료, 자동 검증, 실제 사용자 관찰, 배포 여부를 각각 사실대로 구분한다. 푸시/배포 범위는 함께 전달받은 사용자 지시를 따른다.

1. `playConfigOf(state.play)`로 **끝난 판의 실제 설정**(mode, level, levelVersion, help, small, timer, face, autoMove)을 꺼낸다. `playStart(config)`는 설정이 주어지면 전역 `play_settings` 대신 그것으로 새 판을 만든다. 설정 화면의 시작 버튼만 전역 설정을 읽는다.
2. 결과 팝업과 종료 후 보드 아래 버튼: `확인했어요 · 마지막 판 보기`(첫 초점) / `같은 상대와 다시 두기` / AI에게 사람이 이긴 경우만 `다음 단계 도전 · N단계`(10단계에서는 없음) / `설정 바꾸기`. 무승부·패배·함께 두기는 단계를 바꾸지 않는다.
3. 재대결·다음 단계는 그 판의 설정을 마지막 사용 설정으로 기록한다. AI 판은 mode/level/help/small만, 함께 두기 판은 mode/timer/face/autoMove/help/small만 쓴다. AI 판의 타이머 0이 친구 대전 타이머 선택을 지우지 않게 하기 위함.
4. 대국 중 `새 판`은 기존 교체 확인을 유지하고, 확인 시 현재 판 설정으로 시작한다. 종료 후에는 확인 없이 바로 시작한다. `playStop`의 토큰 증가·Worker 종료·시계 정지로 이전 판 콜백을 버린다.

A-1 홈 직접 진입 (`js/app-home.js`, `js/app-session.js`, `js/app-play.js`, `js/mini-knight-tour.js`, `css/style.css`)

3. 전역 이어하기 카드와 `하던 놀이 모두 보기`는 유지한다. 처음 시작하는 사용자에게 주 진입과 같은 선택을 반복하던 `어디서 시작할까요?` 묶음과 일반 추천 카드는 홈에서 뺀다. 시작 추천 값은 프로필 설정에 그대로 남고 완료 직후의 다음 활동 추천도 유지한다.
4. 대전 입구에서 모드 이름을 `컴퓨터와 두기`/`같은 기기에서 함께 두기`로 바꾸고 시작 버튼이 고른 모드를 말하게 한다. 저장 카드에 그 판의 상대·판 종류·수 수를 보여준다. 함께 두기를 온라인으로 표현하지 않는다.
5. 홈에서 들어간 나이트의 뒤로 가기는 홈으로, 놀이터에서 들어간 경우 놀이터로 돌아간다.
