# 프로필 재설계 · 2026-11-04

요청: 고정된 아이/가족/어른 역할을 없애고 사용자가 추가·이름/아이콘 수정·삭제하는 개인 저장 공간으로 만든다. 모든 프로필의 기능과 신규 기본값은 같다. 기록의 교육적 가치를 전제하거나 성장 기능을 확장하지 않는다. 이어하기·설정·꾸미기 보관을 주 용도로 설명하고 상세 기록은 선택해서 본다.

## 데이터와 이관

- 전역 `chess_profiles_v1`: `{version:1, profiles:[{id,name,icon}]}`. 활성 ID는 기존 `chess_active_profile` 유지.
- 프로필 데이터는 기존 `chess.<id>.<key>` 구조 유지. 이름 변경은 ID나 저장 키를 바꾸지 않는다.
- 최초 사용은 프로필 하나. 기존 child/sibling/adult 슬롯 중 기록이 있는 슬롯 및 활성 슬롯은 중립적 이름으로 이관한다. 기존 별/판/설정은 유지하며 ID 기반 역할 분기는 제거한다.
- 삭제는 해당 ID의 데이터만 지운다. 최소 한 프로필을 유지하고 삭제 전 이름과 파일 백업 선택을 제시한다. 전역 이관 표시로 삭제한 예전 슬롯이 다시 생기지 않게 한다.
- 관리 작업은 쓰기 실패 시 되돌리고 성공으로 표시하지 않는다. 일반 게임의 기존 안전 저장/임시 메모리 폴백은 유지한다.

## 화면

프로필·설정에서 사람 선택, 추가, 수정, 현재 프로필 내보내기/삭제, 파일 불러오기를 제공한다. 프로필에는 이름과 아이콘만 있으며 나이/역할/기능 제한이 없다. 게임의 난이도·소리·시작 추천은 각자가 바꿀 수 있는 같은 설정이다. 나이트의 같은 판 전달도 대상 프로필 선택으로 바꾸고 기존 대상 판 교체를 확인한다.

## 기기 이동

`chess-kids-profile` JSON 파일 v1에 이름·아이콘 및 그 프로필의 로컬 데이터만 담는다. 진행 중 판/되돌리기·완료/별·꾸미기·게임 설정을 포함한다. 다른 가족 데이터와 전역 활성 ID는 포함하지 않는다. 자동 동기화/온라인 계정은 추가하지 않는다.

불러오기는 크기/형식/버전/내용을 먼저 검사하고 미리보기 후 항상 **새 프로필**로 추가한다. 같은 이름은 구별되는 이름을 제안하며 기존 기록을 덮어쓰지 않는다. 잘못된 파일이나 저장 공간 부족에서는 원래 프로필을 보존한다. 파일에 담긴 문자열을 HTML/코드로 실행하지 않도록 표시를 이스케이프하고 가져온 게임 안내/명세의 마크업을 거부한다.

## 완료 기준과 검증

- 추가·수정·전환·삭제 후 재시작해도 독립 기록 유지. 마지막 프로필 삭제 방지.
- 기존 세 슬롯의 실제 기록 보존, ID에 따른 기본 난이도/나이트/꾸미기/가족 전달 차이 제거.
- 한 프로필 내보내기→깨끗한 다른 브라우저 불러오기→진행 판 이어하기·되돌리기 및 별/설정 일치.
- 같은 이름 재수입, 취소, 잘못된 JSON/다른 파일/미지원 버전/유해 내용/큰 파일/저장 실패에서 기존 기록 불변.
- 작은 화면·키보드·입력/오류 초점·파일 다운로드/업로드 실제 브라우저 검수.

구현/검증 결과는 이 문서 하단에 기록한다. 기존 `icons/skins/` 미추적 자산은 변경하지 않는다.

## 구현 결과 · 빌드 2026.11.04.2

- `app-storage.js`: 동적 목록/기존 슬롯 이관/이름·아이콘 수정/독립 삭제/실패 시 롤백. 원래 프로필을 삭제할 때는 예전 비접두 저장 복사본도 지우고 이관 완료 표시는 유지한다. 저장 네임스페이스는 그대로여서 기존 판과 별을 이사하지 않고 보존한다.
- `app-profiles.js`: 프로필·설정 화면, 이름 입력, 삭제 확인과 먼저 내보내기, 실제 JSON 다운로드·파일 선택·미리보기·새 프로필로 가져오기. 중복 이름은 `(2)`, `(3)`처럼 구별한다. 상세 놀이 기록은 선택해서 열며 프로필의 주 용도는 하던 판과 설정 보관이다.
- `app-play.js`, `app-session.js`, `mini-knight-tour.js`: ID/연령에 따른 난이도·나이트 모드·같은 판 전달 분기 제거. 신규 프로필은 모두 같은 기본값. 기존 사용자가 저장한 게임 설정은 유지한다.
- 키보드 팝업 초점 순서에 입력창과 접힌 설정 영역을 반영했다. Service Worker에도 새 스크립트를 넣어 오프라인 사용을 유지한다.

재개/운영:
- 새 백업의 형식 버전을 바꾸면 `parseProfileBackup`의 이전 버전 이관도 함께 설계한다. UI에 쓰이는 게임 필드의 숫자/열거형/보드 검증을 느슨하게 바꾸지 않는다.
- 프로필 ID와 이름은 분리되어 있다. 이름 변경을 저장 키 이동으로 구현하지 않는다. `chess_profiles_legacy_copied`는 예전 데이터 재생성을 막으므로 프로필 삭제 시 함께 지우지 않는다.
- 실제 Android/iOS 파일 선택기와 다른 휴대폰 간 파일 전달은 실기기 관찰 과제다. 자동 검수는 격리된 브라우저 저장소 사이에서 실제 파일을 전달한 결과다. 자동 동기화나 클라우드 백업은 제공하지 않는다.
- 진행 기록이 가치 있는지는 아직 사용자 검증 전이다. 현재는 기록 삭제나 지표 확장 없이 보조 화면에 두고 사용성을 관찰한다.
