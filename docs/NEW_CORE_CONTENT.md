# 새 핵심 콘텐츠 구현 계획

2026-11-05. 사용자가 제안한 다섯 콘텐츠를 순서대로 구현하도록 승인했다.
모두 무료다. 기존 저장/프로필/백업/도움과 진행 중 보드 고정을 보존한다.
새 서버, 결제, 공개 게시판 없이 정적 앱에서 동작한다. 자동 검증은 재미 검증을 대신하지 않는다.

## 순서와 완료 기준

1. **마지막 한 말**: 모든 말을 조작하고 매 수 반드시 잡아 한 말만 남기는 독립 퍼즐. 왕·폰 없이 룩/비숍/나이트/퀸 12판. 직접 편집한 배치, 전체 해법 검사, 선택/잡기/막힘/되돌리기/한 수 힌트/다음 판, 종류별 저장과 프로필 백업. 말별 잡기 횟수 제한 없음. 실제 대전과 다른 퍼즐 규칙을 첫 화면과 도움에 명시.
2. **체스 원정대**: 3전 원정 하나. 첫 판 왕·폰·룩, 이기면 비숍/나이트 영입 선택, 다음 승리 후 상대 배치가 다른 두 경로 선택. 다음 판에서는 말 복구, 패배/무승부는 같은 판 재도전, 승리해야 진행. 표준 체스와 기존 10단계. 원정의 선택/단계/난이도는 대전 저장에 함께 보존. 첫 원정부터 다시 할 때 저장 교체 확인. 장비·재화·마법 없음.
3. **우리 팀 체스**: 두 이름을 입력하고 같은 흰색 팀으로 컴퓨터와 교대. 내 수를 둔 다음 컴퓨터가 응수하면 다음 팀원 차례. 정상 판/짧은 판/짧은 배치 3개, 난이도 선택. 차례 표시, 되돌리기/복원/재대결에서 순서 보존. 함께 생각하기는 판 위 후보 수 표시(실제 이동 아님). 원격 대전/개인 기여도 점수 없음.
4. **승부의 한 장면**: 승격/수비/마무리 각 2장면. 정해진 수를 강요하지 않고 표준 체스로 계속 대국. 목표 달성과 대국 승패를 별도로 표시. 승격은 실제 흰 폰의 승격, 수비는 시작 체크에서 합법적으로 벗어나기, 마무리는 실제 백의 메이트로 판정. 목표 이후에도 대국 계속 가능. 재도전은 같은 초기 장면/난이도. 검증용 수순으로 목표 도달 검사. 자동 대국 분석 없음.
5. **내가 만든 도전장**: 5×5 나이트 경로를 직접 작성하고 유효한 3~25칸 경로를 문제로 확정. 경로 밖은 사용 불가 칸. 만든 경로는 해법 증거이며 다른 완주도 허용. 출제/도전 상태 분리, 풀이 숨김, 같은 기기에서 건네기, 되돌리기·한 수 도움·다시 풀기. 프로필에 여러 문제와 작성 중 경로 보존/파일 백업. 공개 공유 서비스 없음.

## 공통 설계

- 홈의 주 진입 3개는 유지. 전체 놀이에서 신규 콘텐츠 발견, 대전 입구에도 원정/협력/장면 진입 제공.
- 독립 퍼즐은 새 세션 종류를 등록. 대전 기반 콘텐츠는 `play.content`로 모드/선택/초기 배치를 저장하고 기존 엔진·안내·AI·타이머를 재사용.
- 새 콘텐츠 세션/자료가 담긴 백업은 버전 3. 구버전 앱이 다른 게임으로 오인해 열지 않도록 거절하며 새 앱은 v1/v2를 계속 읽는다.
- 외부 백업은 콘텐츠 ID/상태/좌표/기물/경로/이름을 검증. HTML에 사용자 이름을 직접 넣지 않는다.
- 신규 안내는 기존 고정 상태 영역 또는 토스트/모달. 콘텐츠 추가로 진행 중 보드를 밀지 않는다.
- 종료 후 다음 선택은 사용자 클릭으로만 진행. 기존 AI 강도는 몰래 바꾸지 않는다.

## 검증과 전달

단계별 의미 있는 단위 검사와 커밋. 신규 전체 흐름은 360×780/768×1024/1280×900 실제 브라우저에서 검증(보드 고정/저장복원/백업/키보드/모달 포함). 마지막에 기존 단위·브라우저 회귀 검사와 오프라인 자산 검사를 실행한다. 구현/자동 검증/사용자 관찰/배포를 구분하여 기록한다. 이번 요청은 구현이며 배포는 별도 요청 시 수행한다.

## 관찰 과제

- 마지막 한 말: 막힘 뒤 스스로 되돌려 다른 순서를 시도하는가.
- 원정: 다른 영입/경로로 다시 출발하는가.
- 협력: 아이가 자기 차례를 기다리고 직접 선택하는가.

- 도전장: 다른 사람이 푼 뒤 두 번째 문제를 만드는가.

### 진입과 의도적으로 제한한 범위

- `홈 → 놀이터 · 전체 놀이`: 새 다섯 콘텐츠와 기존 놀이 모두 제공.
- `홈 → 체스 대전 → 새로운 대전`: 원정/협력/한 장면 진입.
- 원정·협력·장면은 기존 대전 저장 슬롯을 공유한다. 새 판을 실제 시작할 때 교체 확인하며 취소하면 원래 판이 남는다. 마지막 한 말/도전장 풀이에는 각각 독립 저장 슬롯이 있다.
- 원정은 한 개의 3전 원정, 영입 2종·마지막 경로 2종이다. 적 AI의 성격을 새로 만들거나 난이도를 숨겨 조정하지 않는다. 첫 전투는 왕·폰·룩, 다음 전투에는 고른 동료가 실제 배치에 추가되고 마지막 경로는 상대 기물·룩 위치가 다르다. 전투 완료 뒤 다음 선택을 미뤄도 원정 저장이 남는다.
- 협력은 같은 기기에서 같은 흰색 팀을 교대로 조작한다. 이름은 프로필 역할과 관계없다. 후보 표시만으로 이동/차례/undo 기록을 만들지 않는다. 실제 이동·되돌리기에는 임시 후보를 지운다.
- 수비 장면의 목표는 **처음 체크에서 벗어나기**다. 역전 승리나 강한 상대에게 반드시 비기는 판이라고 보장하지 않는다. 승격 목표도 대국 승리와 다르다. 정해진 검증 수순 외의 합법적인 해결을 인정한다.
- 도전장은 5×5의 3~25칸 경로, 프로필당 최대 100개. 만들던 경로도 자동 보관한다. 같은 기기에서 문제만 보여주거나 프로필 파일로 다른 기기에 전달한다. 개별 문제 공유 코드·공개 목록·순서 표식 편집은 이번 구현에 없다. 저장된 출제 경로는 해법의 증거일 뿐 강제 정답이 아니다.
- 새 콘텐츠 자료가 있는 백업은 v3, 기존 v1/v2도 계속 읽는다. 구버전에서 v3를 거절하는 동작은 의도된 호환 보호다. 새 콘텐츠를 일반 체스/기존 나이트로 잘못 여는 일을 막는다.

이번 기능의 구현 완료를 사용자에게 재미가 검증됐다는 뜻으로 읽지 않는다. 상단 관찰 과제를 실제 아이·어른에게 진행하고, 특히 솔로 12판의 체감 순서와 원정 3전의 길이를 조정한다. Android/iOS 실기기 터치·파일 전달 경로는 아직 검증하지 않았다. 운영 배포는 별도 지시 전에는 하지 않는다.

## 사용자 피드백 반영 · 2026.11.05.4

- ‘마지막 한 말’을 **잡아서 하나 남기기**로 이름 변경. 선택→잡기→한 개 남기기 설명, 실제 말 이동 애니메이션 및 이동 중 중복 입력 방지. 완료 직후 보드 바로 아래에 다음 문제/여기까지 표시.
- 공통 완료/다음 진행 버튼을 오른쪽으로 배치. 다음 진행 모달도 같은 방향 적용.
- 콘텐츠 대전 화면의 보드 크기를 화면 높이에 맞추고 중복 잡은 말 영역·긴 설명을 줄여 undo/힌트/시범/새 판/저장 종료를 한 화면에 배치. 진행 중 공간은 고정.
- 원정·협력·장면 저장을 종류별 아카이브로 보존. 다른 종류의 저장판은 해당 콘텐츠의 이어하기/새 판 확인에 표시하지 않음. 기존 저장판도 처음 사용할 때 보존·인식.
- 도전장에 별도 **판 모양·시작점 설계** 추가: 5/6/7 크기, 구멍 칸 토글, 시작점 이동. 완주 가능성을 솔버로 확인한 뒤 문제 저장. 불가능과 탐색 예산 초과를 구분. 기존 직접 경로 만들기도 유지.
