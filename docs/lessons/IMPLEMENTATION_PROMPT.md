# 다른 코딩 에이전트에게 전달할 프롬프트

아래 내용을 그대로 전달하세요.

---

이 저장소에 ‘직접 두면서 배우는 체스 수업’을 구현해줘.

먼저 `docs/lessons/INTERACTIVE_LESSONS_DESIGN.md` 전체와 `docs/lessons/LESSON_SCENES_V1.json`을 읽고 현재 코드·Git 상태·AGENTS 지침을 확인해줘. 과거 제품 전략 문서 전체를 구현 목록으로 해석하지 말고 이번 명세의 첫 체험 과정 범위를 따라줘.

이번 범위는 **내 말 지키기 첫 3수업**이야. 상대가 노리는 말 찾기, 안전한 곳으로 피하기, 잡은 다음도 살펴보기. 각 수업에 보기·함께 연습·혼자 적용을 넣어 총 9개 장면, 도움·분기 응수·실제 이동 애니메이션·재시도·undo·완료·다음 수업까지 완성해줘. 수업별 저장·프로필 백업 v5·이전 파일 호환과 마지막 초기 배치에서 표준 대전으로 연결하는 흐름도 포함해줘.

교재 JSON은 현재 규칙 엔진으로 확인한 배치와 예시 수순이야. 이를 유일 정답으로 하드코딩하지 말고 명세의 성공 술어로 여러 합법 해법을 인정해줘. 검증 수순이 없는 실패 분기는 억지로 만들지 마. 숨은 체크/핀이나 잘못된 설명을 발견하면 교재를 최소 수정하고 그 근거를 문서에 기록해줘.

최근 사용자 피드백을 반드시 반영해줘: 360×640에서도 다음 버튼과 필수 조작이 보이고, 다음 진행은 오른쪽에 있어야 해. 설명·피드백·완료 중에도 체스판 위치를 고정하고, 말을 잡을 때 이동 과정을 보여줘. 다른 게임의 저장판을 수업 이어하기로 표시하지 말고, 여러 수업을 오가도 각각 이어할 수 있게 해줘. 기존 무료 기능, 가족 프로필의 동일 기능, 기존 저장·도전장·파일 백업을 유지해줘.

명세 §9 순서로 구현하고 목적별로 커밋해줘. `npm test`, 기존 브라우저 회귀와 신규 실제 클릭/키보드/오프라인/파일 이동 검사를 실행해줘. phase를 직접 성공으로 바꾸는 테스트로 실제 수업 흐름 검증을 대신하지 마. 이동·교재 응수 중 화면/프로필 전환 및 앱 종료도 검사해줘.

결제·구독·가격표·잠금·생성형 AI 코치·영상·서버는 이번 범위가 아니야. 기존 미추적 `icons/skins/`는 사용자 자산이니 수정하거나 커밋하지 마.

`docs/lessons/IMPLEMENTATION_PROGRESS.md`를 만들어 변경 파일, 세부 결정, 실행한 검증과 결과, 남은 교육 검수/사용자 관찰을 기록해줘. 구현 완료·자동 검증·실제 교육/사용자 검수·배포를 구분해서 보고해줘. 이번 요청은 구현·검증·커밋까지이며 푸시/운영 배포는 별도 지시를 받기 전에는 하지 마. 명세가 충분한 부분은 재확인 질문 없이 끝까지 진행해줘.
