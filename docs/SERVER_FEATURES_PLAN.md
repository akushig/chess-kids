# 서버를 쓰는 기능 설계: 구글 드라이브 동기화 · 친구 · 온라인 대국

작성: 2026-11-08 · 상태: **설계만, 구현 안 함**

> 같은 날 추가: 서버 없이 두 기기를 직접 잇는 **두 기기 대전(같은 방 QR · 멀리서 초대장 · 편지)**은 구현했다 → [두 기기 대전](TWO_DEVICE_PLAY.md). 아래 §1 드라이브 동기화와 §3의 친구 코드·중계 서버는 여전히 설계만이다. §3의 작은 서버는 이제 '멀리서 실시간이 막히는 망(대칭형 NAT)을 위한 신호·중계(TURN)'로 쓰임새가 좁혀졌다.

사용자 말(2026-11-08): "서버비용이 최소로 드는 방향으로 일부 서버 자원을 활용할 수는 있어. 서버 자원을 활용할 경우 구글 드라이브에 프로필 동기화, 친구추가, 온라인 대국 등을 만들어볼 수 있을 것 같아."

이번 작업에서 구현하지 않은 이유: 세 기능 모두 사용자 계정(구글 클라우드 프로젝트·OAuth 클라이언트, 서버 계정)과 아동 개인정보에 대한 결정이 먼저 필요하다. 계정 없이 만든 코드는 실제로 동작하는지 확인할 수 없다.

## 1. 구글 드라이브 프로필 동기화 — 서버 비용 0원

이미 있는 **프로필 파일(내보내기/불러오기)**을 그대로 사용자의 구글 드라이브 '앱 전용 폴더'에 저장한다. 우리 서버가 없다.

- 로그인: Google Identity Services(토큰 방식, 브라우저에서만). 범위는 앱 전용 폴더(`drive.appdata`) 하나. 사용자의 다른 파일은 볼 수 없다.
- 저장 위치: 앱 전용 폴더의 `chess-profile-<프로필ID>.json`(지금의 `createProfileBackup()` 결과).
- 동기화 규칙(처음 버전): 수동 "드라이브에 저장 / 드라이브에서 불러오기" + 앱을 닫을 때 자동 저장. 같은 프로필을 두 기기에서 동시에 바꾼 경우에는 덮어쓰지 않고 "이 기기 / 드라이브 중 어느 쪽을 쓸까요?"를 묻는다(파일의 저장 시각과 마지막 동기화 시각 비교).
- 가져올 때는 지금의 `parseProfileBackup()` 검사를 그대로 거친다(변조·모르는 형식 거부).
- 구매 권한은 드라이브에 넣지 않는다(스토어 복원으로 처리).
- 필요한 것(사용자): 구글 클라우드 프로젝트, OAuth 동의 화면, 웹 출처와 앱 패키지가 등록된 클라이언트 ID. 아동용 앱이므로 **보호자 계정으로 로그인**하는 흐름으로 안내한다. 범위의 심사 등급과 Families 정책 요건은 착수할 때 최신 공식 자료로 확인한다.

## 2. 친구와 같은 판 도전 — 서버 없이 먼저

실시간이 아니어도 되는 친구 기능은 서버 없이 만들 수 있다. 이미 '내가 만든 도전장'이 같은 방식(공유 코드로 같은 판 열기)이다.

- 승급 과정 판·체스 수업 판·나이트 규칙 판을 **판 번호(시드) 코드**로 친구에게 보내면 같은 판이 열린다(생성기가 같은 시드 → 같은 판).
- 결과(성공·수 수)를 짧은 코드로 돌려보내 비교한다. 순위표는 만들지 않는다.

## 3. 친구 추가와 실시간 온라인 대국 — 작은 서버

| 항목 | 제안 |
|---|---|
| 서버 | Cloudflare Workers + Durable Objects(대국 방 하나 = 객체 하나, 웹소켓). 또는 Firebase Realtime Database. 무료 사용량 안에서 시작할 수 있는지 착수할 때 최신 요금으로 확인 |
| 친구 추가 | 계정·검색 없이 **보호자가 직접 전한 6자리 친구 코드**로만. 공개 매칭 없음 |
| 대국 | 방 서버가 수를 중계하고, 서버에서도 같은 규칙 엔진(`js/chess.js`)으로 합법인지 확인. 연결이 끊기면 판 상태를 방에 30분 보관 |
| 대화 | 채팅 없음. 정해진 이모지 반응(👍 😮 🙂)만 |
| 저장하는 정보 | 별명과 친구 코드, 진행 중인 판. 실명·연락처·위치 저장 안 함 |
| 안전 | 차단·신고 버튼, 보호자 화면에서 온라인 기능 끄기(기본 꺼짐) |

- 아동 개인정보: 14세 미만 아동의 정보를 처리하면 법정대리인 동의가 필요하다(개인정보 보호법). 스토어의 아동 정책(Families 등)도 함께 지켜야 한다. 온라인 기능은 이 검토를 마친 뒤에 켠다.
- 이전 제품 판단(`docs/PRODUCT_STRATEGY_AND_PAID_CONTENT.md`)대로 관찰된 것은 '같은 기기 대면 대전'이다. 원격 대전 수요는 아직 확인되지 않았다.

## 4. 추천 순서

1. 구글 드라이브 동기화(서버 0원, 휴대폰을 바꿀 때 가장 쓸모 있음)
2. 판 번호 코드로 친구와 같은 판 도전(서버 없음)
3. 친구 코드 + 실시간 대국(작은 서버, 아동 개인정보 검토 뒤)

착수할 때 사용자에게 필요한 것: 구글 클라우드 프로젝트·OAuth 클라이언트 ID(1), 서버 계정 선택(3), 개인정보처리방침 문안 확인(1·3).
