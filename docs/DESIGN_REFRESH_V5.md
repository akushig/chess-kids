# 화면 디자인 정리 v5 · 2026-11-08

요청: "체스 앱 전체를 재평가하고 개선점이 있다면 개선해줘. 특히 UI/UX, 레이아웃, 디자인적 요소들을 집중적으로 확인해줘. 메인 메뉴만 하더라도 글자가 줄줄인 경우와 제목만 있는 경우와 아이콘이 있고 없고 등 일관성이 다소 떨어져. 그리고 텍스트에 따라 버튼이 밀리기도 하고. 전체적인 디자인도 다소 답답해."

예전 요청("웹사이트 같지 않게, 게임처럼")은 그대로 지킨다. 색 타일·눌리는 버튼·나무 판은 남기고, 모양의 규칙을 하나로 맞췄다.

## 1. 진단 (바꾸기 전 화면 18종, 360·1280px 촬영)

| 문제 | 원인 | 어디서 |
|---|---|---|
| 전체가 답답하고 무거움 | 글꼴을 700·900 굵기만 불러와 설명 문장까지 모두 굵게 보임 | 모든 화면 |
| 메뉴마다 모양이 다름 | 주 메뉴(색 3D 버튼)·보조 메뉴(흰 카드, 아이콘 박스 없음)·수업 카드(초록)가 서로 다른 규칙 | 홈, 놀이터 |
| 설명 길이에 따라 카드 높이가 달라짐 | 설명 줄 수 제한·높이 고정 없음, 제목 "기사의 여행 · 나이트 투어"가 두 줄로 꺾임 | 홈, 놀이터 |
| 글 때문에 버튼이 밀리거나 꺾임 | 폭을 내용에 맞춰 줄이는 배치 | "저장하고 나가기", "같은 기기에서 함께 두기", "☰ 판 고르기 · 0/15", "왕 구하기 도움 켜짐" |
| 버튼 종류가 너무 많음 | 초록·산호·회색 그러데이션·흰 알약·테두리 카드가 한 화면에 섞임 | 대전 설정 |
| 같은 기능이 두 번 | 위 프로필 버튼과 아래 "👤 프로필 · 설정", 별 막대가 따로 | 홈 |
| 수업 카드 밖에 버튼 세 개가 따로 붙음 | 카드 + 별도 버튼 줄 | 체스 수업 목록 |
| 목록이 가운데로 좁게 몰림 | 가운데 정렬 상자 안에서 폭 지정 없음 | 잡아서 하나 남기기, 우리 팀 체스, 원정대 |
| 정렬이 섞임 | 같은 상자 안에서 왼쪽·가운데 정렬 혼용, 양옆 여백 8px/16px 혼용 | 내가 모은 별 |
| 글자색이 둘 | 갈색(#3D2B1F)과 남색(#243343)이 섞임 | 전체 |
| 이름이 둘 | "놀이터"와 "전체 놀이"가 같은 화면을 부름 | 뒤로 버튼 |
| 긴 화면에서 배경이 끊김 | 배경을 `body`에 고정 첨부 | 긴 화면 |

## 2. 규칙 (`css/style.css` 끝의 "디자인 정리 v5" 묶음)

- **글자**: 본문 500, 제목 900. `index.html`에서 Noto Sans KR 500을 추가로 불러온다. 설명 문장은 굵게 쓰지 않는다. 글자색은 남색 한 가지(`--ink`, `--ink-2`, `--ink-3`).
- **배경**: 화면에 고정된 그러데이션 한 장(`body::before`). 예전보다 옅게.
- **표면**: 흰 카드 + 옅은 테두리(`--line`) + 그림자 한 가지(`--shadow-1`). 눌리면 살짝 내려간다.
- **버튼 세 가지**: 주 행동 `action-btn green`, 놀이 시작 `action-btn`(산호), 보조 `action-btn secondary`(흰색). 모두 같은 둥글기·높이(48px 이상)·눌림.
- **메뉴 타일**: 아이콘 칸 + 제목 한 줄 + 설명 최대 두 줄. 높이가 고정이라 글 길이와 상관없이 같은 크기다.
  - 홈의 큰 색 타일(`menu-btn`): 주 진입 3개.
  - 목록 행 카드(`menu-btn menu-row`, `choice-card`): 놀이터, 새로운 대전, 배운 말로 첫 대전, 한 수 발견 단계. 흰 카드에 색 아이콘 칸.
- **묶음 제목**: 모든 화면에서 같은 크기·굵기·왼쪽 정렬.
- **선택 칩**: 흰 알약, 고르면 초록 테두리. 글이 길면 칩이 줄을 바꿔 한 줄씩 차지한다(글자가 꺾이지 않음).
- **폭**: 본문은 최대 560px. 머리줄(뒤로 + 제목)도 같은 폭이라 왼쪽 끝이 맞는다.

## 3. 화면별 변경

| 화면 | 바뀐 점 |
|---|---|
| 홈 | 위 줄에 프로필(⚙)·별 개수·꾸미기를 모음. 아래쪽 중복된 프로필·설정 버튼과 별 막대를 없앰. 주 진입 3개는 같은 높이의 색 타일(대전=킹, 기사의 여행=나이트, 처음 배우기=룩). 보조 3개(체스 수업·놀이터·모험 지도)는 세 칸 세로 타일 |
| 체스 대전 설정 | 상대 → 난이도 → 판 설정 → 시작 순서. 상대 카드 두 장이 같은 구조. 시작 버튼 하나를 크게, 추천은 흰 보조 버튼. 첫 대전·새로운 대전·체스 수업은 같은 행 카드 |
| 판이 있는 놀이 화면 | 판 아래 버튼을 흰 카드형으로 통일(힌트만 노랑). "저장하고 나가기"가 꺾이지 않음. 안내 칸 글과 듣기 버튼이 겹치지 않음. "놀이 설정" 접는 상자를 카드로 |
| 체스 수업 목록 | 카드 하나에 시작/이어하기(카드 전체) + 아래 두 칸(판 고르기·무한 연습). 처음 상태의 "처음 · 15판"은 아래 "0/15"와 겹쳐 숨김. 제목 앞 번호 중복 제거 |
| 놀이터 | 모든 놀이가 같은 행 카드. 표준 체스 콘텐츠(새로운 대전)는 맨 아래로 |
| 한 수 발견 | 같은 문구가 반복되던 2열 카드 → 아이콘 행 카드, 해결 수 표시 |
| 잡아서 하나 남기기 | 가운데로 좁던 목록 → 번호 배지 카드(완료는 ✓). 설명 문장 중복 오타 수정 |
| 원정대·우리 팀·도전장·한 장면 | 입력칸·버튼을 본문 폭으로. 원정대 세 단계는 누르는 카드처럼 보이지 않게 단계 목록으로 |
| 내가 모은 별 | 별 개수 카드(꾸미기 바로가기) → 출처 4칸 → 내가 익힌 것 → 별로 여는 꾸미기. 모두 같은 폭·왼쪽 정렬 |
| 뒤로 버튼 | 놀이터로 가는 버튼 이름을 "← 놀이터"로 통일 |

바꾸지 않은 것: 판·말 모양과 크기, 게임 규칙, 저장 형식, 판 위치가 움직이지 않는 레이아웃 규칙, 대화창 구조.

## 4. 검증

- 빌드 `2026.11.08.2`: 단위 142/142, 브라우저 15종 모두 통과(360·640~1280px, 동작 줄이기, 오프라인 포함). 판 위치 고정 156가지 상황도 그대로 통과.
- 중간에 걸렸다 고친 것: 놀이터에서 하던 판이 있으면 설명이 "▶ 하던 판 이어하기"로 통째로 바뀌어 무슨 놀이인지 사라짐 → 홈과 같이 "▶ 이어하기 + 원래 설명". 버전 글자를 다시 옅게 만든 것(예전 피드백으로 진하게 했던 것) → 되돌림. 잡아서 하나 남기기 카드의 읽어주기 이름에서 번호가 빠짐 → 카드 이름에 번호 포함.
- 바뀐 구조에 맞춰 고친 테스트: 수업 카드 순서(이어하기 → 판 고르기 → 무한 연습), 홈 이름(`기사의 여행`, `놀이터`, `프로필 · 설정 · 이름`), 대전 상대 카드(`함께 두기`), 수업 카드 버튼 선택자, 원정대 카드 이름(꾸밈 아이콘은 읽지 않음).
- 화면별 스크린숏: `docs/product-review/design-v5/` (바꾸기 전 `before-`, 뒤 `after-`).
