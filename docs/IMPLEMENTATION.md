# 개발 진행 기록

분석 기준선: `7fe3cfb`. 원래 진단 자료는 당시 앱의 스냅샷이며, 현재 동작은 아래 구현·검증 기록을 기준으로 확인한다.

## 1단계 — 판정과 복구

- 공격 범위와 이동 가능 범위를 분리하고 불법 수의 상태 변경을 차단.
- 회피 미션 실패 설명·위험 표시·즉시 되돌리기 추가, 폰 중복 좌표와 킹 안전 검사 수정.
- 잘못된 퍼즐을 검증된 15개 상황 문제로 교체. 실제 목표와 모든 상대 응수로 채점, 대체 정답 허용, 오답 즉시 재시도.
- 수집·폭탄 최고 보상 조건과 나이트 중간 성과 저장 수정.
- 활성 화면에 힌트를 표시하고 화면 이탈 콜백 취소.
- 검증: `node --test tests/content.test.cjs` 5개 통과. 모험 48개·수집 5개·폭탄 5개의 해결 경로 재생. 별도 python-chess로 15개 퍼즐의 모든 정답 집합 대조 통과.

## 2단계 — 스스로 계속하기

- 공통 세션·되돌리기·난수 상태 복원·새로고침 후 재개 추가.
- 체크 공격선, 대응 가능한 말, 피하기/잡기/막기, 불가능한 이유, 한 수 힌트·시범 추가.
- 컴퓨터 대전은 내 차례까지 되돌리고, 친구 대전은 양쪽 동의 후 되돌리기. 친구 시계는 없음이 기본.
- 룩 기본 길 8개를 4×4·5×5로 재설계하고, 새 콘텐츠 ID와 기존 별 보존 이관 추가.
- 나이트 산책·10칸 탐험·기존 전체 완주, 갈림길 되돌리기·시범·교대 탐험 추가.
- 저장 실패 시 게임은 계속되며, 원래 로컬 기록을 삭제하지 않는 저장 계층 추가.
- 검증: Node 회귀 12개 통과. 실제 Chromium 모바일 화면에서 클릭·실패 복구·체크 차단·나이트 목표·재실행 후 복원과 모든 게임 화면을 검수.

## 3단계 — 콘텐츠와 가족 경험 연결

- 홈을 이어하기·모험·놀이터·대전으로 정리. 마지막 단계에서도 다음 놀이와 마무리 선택 제공.
- 가족 3개 프로필에서 판·별·스킨·설정을 따로 보관. 완료 도장에 도움/시범/협동 여부 기록.
- 나머지 말의 초반 난이도와 순서를 보정하고 선택 도전을 표시. 원래 콘텐츠 ID 보존.
- 수집은 1점프·2점프부터 시작하고 제한 수는 선택. 복잡한 순찰은 기본 수집판에서 제외. 수집과 폭탄은 공통 이동 코드를 사용.
- 디펜스의 남은 하트·끝줄·접촉·중복 점유 규칙 통일, 예고대로 이동하는 결정적 적 행동 추가.
- 무작위 생존 대신 다음 위치와 공격 범위를 보여 주는 4단계 왕 지키기 도입. 목표 도달 즉시 완료하고 원하면 다음 단계로 진행.
- 검증: Node 회귀 16개 통과. 디펜스 4단계 승리 경로·중복 점유, 왕 지키기 4단계 미래 안전과 완주 경로 검증. Chromium 모바일 조작·재개 검수 통과.

## 4단계 — 정규 규칙·접근성·오프라인·최종 검수

- 캐슬링과 4가지 승격을 UI·체스 엔진·AI에 추가. 캐슬링 권리·앙파상·반복국면·되돌리기 상태 일치.
- 컴퓨터 계산 시간 제한과 화면 이탈 시 Worker 취소. 시계는 도움·승격·되돌리기 선택 중 멈춤.
- 동작 완료를 애니메이션 이전에 원자적으로 저장해, 이동 중 앱 종료·재시작에도 일관된 판 복원.
- 종류별 최근 판 보관, 콘텐츠 ID로 재배열 후 복원, 실패한 판도 다시 열어 되돌리기. 저장 불가 시 현재 세션은 메모리로 유지.
- 나이트 같은 판을 다른 가족 프로필로 전달. 번갈아 한 흔적과 시범·도움 사용을 독립 해결과 구분.
- 마지막 콘텐츠 검수에서 성 지키기를 적 1개→2개→퀸→웨이브 도전으로 완화. 왕 지키기는 안전한 깃발 찾기로 바꿔 기다리기만으로 완료되지 않게 함.
- 모든 고정 콘텐츠 ID와 기존 별 이관 정리. 대전의 첫 포획·체크 해소·한 판 완료에도 한정 성취 부여.
- 확대 허용, ARIA 행·칸 구조, 화살표/Enter/Space 보드 조작, 기물·진영 배지, 선택형 한국어 음성·동작 감소와 큰 화면 대응.
- 앱/서비스워커 빌드 버전을 통일하고 모든 필수 자산을 선캐시. 진행 중 강제 새로고침 대신 홈에서 저장 후 업데이트.
- 검증: 자동 회귀 **29개 통과**, 독립 체스 국면 **98개**의 앱·AI 합법수 일치, 초기 배치 3깊이 **8,902개** 일치. 상황 퍼즐 **15개**의 모든 정답 집합 독립 대조 통과.
- 실제 Chromium에서 360×780 / 768×1024 / 1280×900 화면의 키보드·프로필·승격·캐슬링·가족 같은 판을 검수. 오프라인 새로고침·스킨·컴퓨터 응수 확인.

최종 화면과 기계 검수 결과는 [QA 기록](qa/README.md)에 남겼다. 실제 어린이·성인 플레이테스트와 실물 iOS/Android 기기의 음성·터치 체감은 별도 확인이 필요하다.

## 나이트 투어 UX 재정리 — 2026.10.25.5

- 자주 사용하는 갈림길 알림을 보드 위의 명시적인 스위치로 노출. 갈림길·이미 완주 불가능한 상태·탐색 한도 초과를 구분하고 산책/탐험에서도 각 목표로 판정.
- 힌트 기본값을 전체 경로로 복원. 동일 패널에서 전체 번호 경로/다음 한 수를 선택하고 닫을 수 있게 함. 이동하면 오래된 힌트를 제거하고 되돌리기·재개에는 해당 판의 경로를 복원.
- 중복되는 나이트 시범 버튼을 제거하고 주 조작을 되돌리기·힌트·다시 하기로 정리. 나이트 투어로 바로 진입하고 짧은 목표는 상단에서 선택.
- 시작 위치를 게임 설정의 모서리/무작위 선택으로 정리. 진행 중 설정은 판을 바꾸지 않고 다음 새 판에 적용. 다시 하기는 같은 시작점을 보존.
- 가족 기능은 접힌 게임 설정에 배치하고 보드 크기 선택을 프로필에 저장.
- 전체 자동 검사 37개, 모바일/태블릿 나이트 전용 실제 입력 검사, 기존 브라우저·오프라인 회귀 통과. 이전 릴리스의 진행 중인 투어 복원도 확인.
