# 개발 진행 기록

분석 기준선: `7fe3cfb`. 원래 진단 자료는 당시 앱의 스냅샷이며, 현재 동작은 아래 구현·검증 기록을 기준으로 확인한다.

## 1단계 — 판정과 복구

- 공격 범위와 이동 가능 범위를 분리하고 불법 수의 상태 변경을 차단.
- 회피 미션 실패 설명·위험 표시·즉시 되돌리기 추가, 폰 중복 좌표와 킹 안전 검사 수정.
- 잘못된 퍼즐을 검증된 15개 상황 문제로 교체. 실제 목표와 모든 상대 응수로 채점, 대체 정답 허용, 오답 즉시 재시도.
- 수집·폭탄 최고 보상 조건과 나이트 중간 성과 저장 수정.
- 활성 화면에 힌트를 표시하고 화면 이탈 콜백 취소.
- 검증: `node --test tests/content.test.cjs` 5개 통과. 모험 48개·수집 5개·폭탄 5개의 해결 경로 재생. 별도 python-chess로 15개 퍼즐의 모든 정답 집합 대조 통과.

## 2단계 — 스스로 계속하기

- 공통 세션·되돌리기·난수 상태 복원·새로고침 후 재개 추가.
- 체크 공격선, 대응 가능한 말, 피하기/잡기/막기, 불가능한 이유, 한 수 힌트·시범 추가.
- 컴퓨터 대전은 내 차례까지 되돌리고, 친구 대전은 양쪽 동의 후 되돌리기. 친구 시계는 없음이 기본.
- 룩 기본 길 8개를 4×4·5×5로 재설계하고, 새 콘텐츠 ID와 기존 별 보존 이관 추가.
- 나이트 산책·10칸 탐험·기존 전체 완주, 갈림길 되돌리기·시범·교대 탐험 추가.
- 저장 실패 시 게임은 계속되며, 원래 로컬 기록을 삭제하지 않는 저장 계층 추가.
- 검증: Node 회귀 12개 통과. 실제 Chromium 모바일 화면에서 클릭·실패 복구·체크 차단·나이트 목표·재실행 후 복원과 모든 게임 화면을 검수.

## 3단계 — 콘텐츠와 가족 경험 연결

- 홈을 이어하기·모험·놀이터·대전으로 정리. 마지막 단계에서도 다음 놀이와 마무리 선택 제공.
- 가족 3개 프로필에서 판·별·스킨·설정을 따로 보관. 완료 도장에 도움/시범/협동 여부 기록.
- 나머지 말의 초반 난이도와 순서를 보정하고 선택 도전을 표시. 원래 콘텐츠 ID 보존.
- 수집은 1점프·2점프부터 시작하고 제한 수는 선택. 복잡한 순찰은 기본 수집판에서 제외. 수집과 폭탄은 공통 이동 코드를 사용.
- 디펜스의 남은 하트·끝줄·접촉·중복 점유 규칙 통일, 예고대로 이동하는 결정적 적 행동 추가.
- 무작위 생존 대신 다음 위치와 공격 범위를 보여 주는 4단계 왕 지키기 도입. 목표 도달 즉시 완료하고 원하면 다음 단계로 진행.
- 검증: Node 회귀 16개 통과. 디펜스 4단계 승리 경로·중복 점유, 왕 지키기 4단계 미래 안전과 완주 경로 검증. Chromium 모바일 조작·재개 검수 통과.

정규 체스 규칙·접근성·오프라인·최종 기기 검수는 진행 중이다.
