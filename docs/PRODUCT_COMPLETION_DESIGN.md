# 제품 완성도 개선 설계 · 인수인계 기준

작성: 2026-11-04. 근거: [전체 검토](PUBLIC_RELEASE_REVIEW.md). 적용 대상은 현재 정적 웹 앱이다.

## 범위와 지켜야 할 계약

어린이가 스스로 시작 → 목표 이해 → 막힘 복구 → 성공 → 다음 활동으로 이어가는 경험을 완성한다. 나이로 기능을 차단하지 않고 경험 수준으로 추천한다. 성인의 표준 대전·10단계 AI·전체 나이트 투어도 유지한다.

스토어 제출, 권리 확인, 개인정보 신고, Android 포장/네이티브 연결은 [별도 보관](DEFERRED_RELEASE_READINESS.md)한다. 이 작업에서 브랜드 자산을 임의 삭제하거나 새 서버·광고·계정을 추가하지 않는다. `icons/skins/`의 기존 미추적 파일도 변경하지 않는다.

필수 불변 조건:
- 메뉴 재진입으로 미완료 저장판을 덮어쓰지 않는다. 새 판 교체는 명시적으로 선택한다.
- 기존 프로필·별·완료 이력·콘텐츠 ID를 유지한다. 저장된 판은 가능한 한 당시 배치를 복원한다.
- 진행 중 안내·결과·설정이 보드 좌표를 바꾸지 않는다. 팝업/고정 토스트를 사용한다.
- 목표 깃발, 합법 이동 점, 위험 패턴, 선택 테두리는 서로 다른 뜻이다.
- 나이트 갈림길 알림·전체 경로·다른 시작점·가족 같은 판을 보존한다.
- 도움받은 성공도 정상 성취다. 선택 도전은 기본 다음 단계에 강제로 끼우지 않는다.

## 구현 구조

- `app-session.js`: 저장판 진입 정책과 다음 활동 선택의 단일 출처. 렌더러는 세션 새로 만들기와 복원을 혼동하지 않는다. `beginActivity`는 명시적인 새 활동 시작의 하위 API로 유지한다.
- `app-core.js`: 공통 대화상자, 기존 고정 토스트/보드 배치 유지. 대전의 특수 이벤트 팝업은 타이머/AI 재개 콜백 계약을 유지하며 점진적으로 공통화한다.
- `content-curriculum.js`: 원래 배치를 보관한 뒤 새 교육 순서와 기술 메타데이터를 적용한다. 한 수 발견은 기본 장면에 반대 배치 연습을 추가하며 별도 ID로 기록한다.
- 콘텐츠 메타데이터는 런타임의 최종 콘텐츠에 부착한다. `missions.js` 후반의 덮어쓰기와 ID 이관을 반드시 확인한다. 원본 배열만 수정하면 실제 앱에 반영되지 않을 수 있다.
- `app-home.js`/`mini-menu.js`: 추천·이어하기·자유 선택을 함께 제공. 경험 선택은 생년월일 수집 없이 프로필 내 로컬 저장한다.
- `app-accessibility.js`: 수동 읽기와 자동 읽기를 분리한다. 음성 기능 부재가 게임을 막지 않는다.
- 결과 UI는 완료 여부→이번 성취→다음 행동 순서. 주 행동 1개와 종료를 우선, 재시도/목록/선택 도전은 보조 행동으로 배치한다.

## 데이터 호환과 실패 처리

세션의 snapshot, history, params 및 기존 콘텐츠 ID를 유지한다. 기술 요약은 기존 이력에서 파생한다. 모험 세션에는 `missionSpec`을 추가 저장하고 `params.curriculumVersion=2`로 배치를 구분한다. 이전 세션에 명세가 없으면 `LEGACY_MISSIONS`에서 당시 배치를 채우며 되돌리기 snapshot에도 같은 명세를 넣는다. 배치를 바꿀 때 진행 중 판의 `state` snapshot을 새 원본 배열로 재초기화하지 않는다. 경험 선호는 미설정 상태를 별도로 취급하고 기존 활동 저장이 있으면 그 활동을 우선한다. 파손된 저장은 기존 검증/안전 저장 경로를 사용한다.

## 검증 명령과 인수인계

`npm test` → `CHESS_BROWSER_EXECUTABLE=<설치된 Chromium 경로> npm run test:browser`. 웹 서버 기본 주소 `http://127.0.0.1:8765`; 필요하면 `CHESS_TEST_URL`을 지정한다. 신규 검사는 기존 문제를 실제 사용자 동선으로 재현하고 저장값/보드 좌표/선택 결과를 확인한다. DOM 문자열 존재만으로 완료 처리하지 않는다.

진행 상황·변경 파일·남은 작업·실제 실행한 검사는 [진행 기록](PRODUCT_COMPLETION_PROGRESS.md)에 갱신한다. 다음 에이전트는 이 문서 → 진행 기록 → 관련 코드/테스트 순서로 읽고 미완료 단계부터 이어간다. 전체 리뷰를 구현 완료로 간주하지 않는다.

실제 어린이·부모 관찰은 별도 필요하다. 최소 과제는 첫 성공, 막힘 복구, 저장판 복귀, 체크 해결, 다음/종료 선택, 부모 시범 후 같은 판 실행이다. 자동 검사로 재미·학습 효과를 입증했다고 쓰지 않는다.
