# 귀엽고 아기자기한 스킨 5종

기존 조각형 스킨과 다른 형태·그림체·분위기로 봉제인형 친구들, 말랑 젤리 놀이터, 크레용 낙서대장, 부릉부릉 자동차, 몽글몽글 구름나라를 추가했다. 기본 스킨은 로열 클래식이며, 새 5종도 모두 무료다. 이전 SVG 스킨은 계속 숨긴다.

공방에서 로열 클래식 다음에 새 5종을 표시한다. 선택 후 **♞ 말 모션 보기**로 이동·공격·피격을 확인한다. 기존 스킨 선택값과 별·진행 기록은 유지한다.

[새 5종 갤러리](playful.html) · [미리보기 이미지](playful.jpg) · [젤리 모션 GIF](playful-motion.gif) · [모바일 공방](playful-workshop.png)

GIF는 표정과 탄성을 살펴보도록 실제 모션을 느리게 녹화했다.

| 스킨 | 그림체와 캐릭터 | 움직임 | 요청문 |
|---|---|---|---|
| 봉제인형 친구들 | 천 질감·바느질, 곰·토끼·펭귄·조랑말 | 부드럽게 뒤뚱거리기, 하트 흔적 | [프롬프트](plush/image-prompt.txt) |
| 말랑 젤리 놀이터 | 밝고 짙은 젤리 몸, 큰 눈과 작은 팔 | 눌렸다 펴지는 탄성, 동그란 충격 | [프롬프트](jelly/image-prompt.txt) |
| 크레용 낙서대장 | 평면 크레용, 해·꽃·성·흔들목마 낙서 | 뚝뚝 끊어지는 이동, 낙서 흔적 | [프롬프트](crayon/image-prompt.txt) |
| 부릉부릉 자동차 | 굵은 윤곽선의 평면 만화, 버스·밴·소방차 | 낮게 달리기, 작은 차체 진동 | [프롬프트](motors/image-prompt.txt) |

캐릭터가 기물 자체가 되도록 원형 받침대와 고전 체스 기둥을 제외했다. 킹의 십자, 퀸의 왕관, 룩의 성벽, 비숍의 뾰족 모자, 나이트의 말 머리, 작은 폰으로 역할을 구분한다. 두 팀은 밝은 따뜻한 색과 짙은 차가운 색으로 나눈다. 작은 화면에서는 기존 기물 이름 배지도 함께 사용할 수 있다.

## 제작과 파일

내장 `image_gen`으로 **테마당 1회, 총 5회** 생성했다. 한 장에 백·흑 12종 × 기본·공격·피격 3포즈를 넣어 총 **180포즈**를 확보했다. 각 테마 폴더에 `source-atlas.png`, 정확한 `image-prompt.txt`, 분리 측정값 `atlas-layout.json`, `preview.jpg`를 보존한다. 실제 게임은 `icons/skins/<id>/atlas.webp`를 사용한다. 이미지 생성 없이 다시 분리하려면 `node scripts/prepare-theme-sprites.cjs plush jelly crayon motors clouds`를 실행한다.

`js/skin-playful.js`에서 새 스킨을 등록하고 `js/skin-royal.js`의 공유 모션에 각 움직임을 적용한다. 새 평면 그림체는 그림자를 줄였으며, 선택한 캐릭터의 대기 모션도 달라진다. 앱의 모션 끄기와 OS 동작 줄이기를 따른다.

검증은 단위 테스트, 모바일·태블릿·PC의 무료 선택·36칸 이미지·미리보기·공격·피격, 전체 16종 오프라인, 기본 스킨·기존 SVG 숨김, 로열 클래식의 특수 수 회귀 검사로 진행한다. 결과는 [playful-qa.json](playful-qa.json)에 기록한다.
