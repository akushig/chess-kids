# 전체 기물 미리보기와 그래픽 스킨 5종

공방 상단 미리보기에서 진영당 4종만 보이던 배치를 바꿔 **백·흑 킹·퀸·룩·비숍·나이트·폰 총 12종**을 모두 표시한다. 미리보기 판의 **말 12종 크게 보기**를 누르면 이름과 함께 확대한다. 확대 화면의 **공방으로 돌아가기**는 선택을 유지한 채 원래 공방으로 돌아온다.

[수정된 미리보기](graphic-preview-mobile.png) · [확대 화면](graphic-detail-mobile.png)

새 5종은 기존 조각형 및 귀여운 캐릭터형과 다른 매체로 제작했다. 모두 무료이고 기본 스킨은 로열 클래식이다. 공방에 보이는 무료 스킨은 총 21종이며 기존 SVG 스킨은 계속 숨긴다. 별·경험치 해금 조건을 추가하지 않았다.

[새 스킨 갤러리](graphic.html) · [전체 이미지](graphic.jpg)

| 스킨 | 그림체 | 모션 | 정확한 생성 요청 |
|---|---|---|---|
| 레트로 픽셀 | 각진 저해상도 게임 그래픽, 제한된 색 | 단계적으로 이동, 형태를 찌그러뜨리지 않음 | [프롬프트](pixel/image-prompt.txt) |
| 네온 회로 | 발광 선과 투명한 내부, 청록·자홍 | 회로 잔상과 투명도 변화 | [프롬프트](neon/image-prompt.txt) |
| 수묵 붓그림 | 거친 먹선·붓자국·여백 | 낮게 미끄러지고 붓자국 흔적 | [프롬프트](ink/image-prompt.txt) |
| 탱그램 공작소 | 나무 도형을 이어 만든 평면 퍼즐 | 딱딱하게 단계적으로 이동, 탄성 변형 없음 | [프롬프트](tangram/image-prompt.txt) |
| 팝아트 히어로 | 굵은 검은 윤곽선과 망점 인쇄 | 경쾌한 돌진과 만화 별 효과 | [프롬프트](comic/image-prompt.txt) |

내장 `image_gen`을 테마당 1회씩 **총 5회** 사용했다. 각 요청에 백·흑 12종 × 기본·공격·피격 3포즈를 6×6 시트 한 장으로 구성해 총 **180포즈**를 확보했다. 각 폴더의 `source-atlas.png`에 투명 원본, `image-prompt.txt`에 요청문, `atlas-layout.json`에 분리 측정값을 보존한다. 실제 게임은 `icons/skins/<id>/atlas.webp`를 사용한다.

ImageMagick으로 다시 분리하려면 `node scripts/prepare-theme-sprites.cjs pixel neon ink tangram comic`을 실행한다. 생성 API 호출은 없다. 픽셀은 최근접 보간과 무손실 WebP, 네온은 발광 외곽 여백을 적용한다. 등록 코드는 `js/skin-graphic.js`에 있다. 앱의 모션 끄기와 OS 동작 줄이기를 따른다.

검증은 모든 스킨의 미리보기 기물 12종 회귀 검사, 새 스킨 및 첨부 화면의 구름 스킨에 대한 모바일·태블릿·PC **18조합** 실제 미리보기·확대·공격·피격 검사, 전체 **21종 오프라인** 검사로 진행했다. 기존 로열 클래식의 캐슬링·앙파상·승격·대면 모드·모션 끄기 회귀 검사도 3개 화면 크기에서 통과했다. [브라우저 결과](graphic-qa.json)
