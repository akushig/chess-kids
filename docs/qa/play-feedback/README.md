# 난이도 설명 팝업과 대전 상태 인지 개선

빌드 `2026.11.03.2` · Node 20.20.2 · Playwright 1.64.1 / Chromium headless.

## 변경

- 난이도 라벨 바로 오른쪽의 `!` 버튼으로 10단계 설명 팝업을 연다. 단계·이름·두는 방식·실제 계산 시간 예산을 모두 표시한다. 긴 표는 팝업 내부에서 스크롤하고 확인 버튼은 항상 보인다. Escape·닫기·확인으로 닫을 수 있으며 선택한 난이도, 페이지 스크롤과 버튼 초점을 유지한다.
- 체크 표시는 왕 구하기 도움 설정과 관계없이 제공한다. 공격받는 왕에 빨간 테두리·무늬·‘체크!’ 꼬리표를 붙이고, 상태창에 ‘왕을 안전하게 하는 수만 둘 수 있어요’라고 안내한다. 친구 대전에서는 양쪽 차례 패널 모두 어느 왕이 체크인지 표시한다.
- 대국 중 각 색의 왕이 처음 체크를 받으면 왕 그림과 규칙을 중앙 팝업으로 설명한다. 확인한 뒤에는 같은 왕의 체크마다 반복해서 대전을 가리지 않는다. 대신 체크 상태창·왕 꼬리표·시간이 지나도 사라지지 않는 설명을 유지한다.
- 잘못된 수 설명이 체크 구조 방법을 가리던 우선순위를 수정했다. 잘못 움직인 이유와 가능한 왕 구하기 방법을 함께 보여준다. 닫았던 설명도 같은 잘못된 수를 다시 시도하면 다시 표시한다.
- 캐슬링에서 왕과 룩을 동시에 애니메이션하고 두 말의 실제 출발·도착 칸을 함께 설명한다. 승격도 어떤 말로 바뀌었는지 설명한다. 확인 전에는 다음 수나 시계가 진행되지 않는다.
- 체크메이트는 누가 이겼는지, 무승부는 왜 끝났는지 중앙에 표시한다. 스테일메이트는 ‘체크가 아니지만 둘 수 있는 수가 없다’고 설명한다. 마지막 판 보기·새 판 시작을 제공하고, 닫은 결과는 ‘결과 다시 보기’나 종료된 보드 누르기로 다시 연다. 종료 후 중복 토스트가 결과 버튼을 가리지 않는다.
- 진행 중인 판에서 확인하지 않은 특별 수 설명은 저장·재개해도 유지한다. 되돌리기·새 판·화면 이탈 때 이전 팝업이 남지 않으며 배경에서 말이 움직이지 않는다. 읽는 동안 시계·AI 응수를 멈추고 다음 플레이어의 시간 예산을 보존한다.
- 팝업·꼬리표는 문서 흐름 밖에서 표시한다. 보드 화면의 진입 애니메이션을 끄고 키보드 초점 복구 시 자동 스크롤을 막아 보드 위치를 유지한다. 음성 안내를 켠 경우 배경 안내가 팝업 읽기를 덮지 않는다.

## 검증

`npm test`: 57개 통과. 필수 체크 안내와 선택형 도움 구분, 오류 설명·구조 방법 동시 표시, 각 왕별 첫 안내 기록의 재개, 캐슬링 두 경로 저장과 되돌리기, 승리 색상·무승부·승격 동시 종료의 우선순위, 한국어·영어 난이도 표를 포함한다.

`npm run test:browser`: 기존 입력·오프라인·캐슬링 24개 조합·10단계 AI·나이트 투어·보드 고정 156개 시나리오와 새 대전 상태 검사를 실행한다. 새 검사는 360×780, 768×1024, 1280×900에서 다음을 확인한다.

- `!`의 위치·터치 영역, 표 10행과 실제 시간, 팝업 내부 스크롤, 키보드 초점 순환·Escape·선택 및 스크롤 유지.
- 도움을 꺼도 체크 왕 표시·필수 설명이 남음. 최초 안내의 배경 입력 차단과 시계 정지. 확인 후 재개와 잘못된 수 재시도의 설명·구조 버튼 보존.
- 캐슬링 두 말의 실제 애니메이션, 출발·도착 설명, 확인 전 AI·시계 정지, 읽지 않은 설명의 새로고침 복원, 확인과 되돌리기.
- 실제 입력으로 이기는 수 실행, 패배·스테일메이트 구분, 종료된 보드·결과 버튼으로 결과 재열기, 새 판 시작, 보드 좌표 유지.
