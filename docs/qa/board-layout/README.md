# 게임 중 체스판 위치 고정

빌드 `2026.10.25.6`.

- 대전의 이동 설명·체크 구조 안내·무승부 사유를 화면 아래 고정 팝업으로 표시한다. 체크 대응 버튼은 그대로 사용할 수 있고, 닫은 뒤 ‘왕 구하기 안내’로 다시 연다.
- 모험·퍼즐·별 모으기·폭탄 해제·성 지키기·왕 지키기의 일시적인 잘못된 이동 설명과 힌트도 같은 팝업을 사용한다. 목표 설명과 진행 정보는 일정한 높이에 남는다.
- 나이트 투어는 갈림길 알림 영역 높이를 고정하고, 전체 경로와 다음 한 수 기능을 유지한다.
- 잡은 말이 처음 생기거나 많아져도 목록 영역 높이는 일정하다. 사람 대전의 차례 패널과 시간 막대도 종료 시 높이가 달라지지 않는다.
- 힌트·결과·설정 영역이 줄어들 때 페이지 높이와 스크롤을 보존한다. 새 판과 재개에서는 이전 화면의 높이를 물려받지 않는다. 키보드 조작 후 초점을 복구할 때 자동 스크롤하지 않는다.

## 검증

`npm test`: 37개 통과. 기존 브라우저 검사에서 실제 입력, 체크 구조, 승격·캐슬링, 저장·재개, 나이트 투어의 갈림길·전체 경로·시작 위치 설정, 오프라인 실행을 확인했다.

`node tests/layout-browser.cjs`: 360·768·1280px에서 AI/사람 대전과 모든 보드 게임의 156개 시나리오를 검사한다. 긴 설명 표시·제거, 체크 진입, 팝업 닫기·다시 열기, 잡은 말 15개, 힌트, 성공·실패, 되돌리기, 음성 버튼 추가, 스크롤한 상태에서 힌트·설정 닫기와 되돌리기, 실제 이동 애니메이션 전후에 보드 x/y/너비/높이를 비교한다. 각 동작 직후 여러 프레임과 애니메이션 완료 후를 모두 확인한다.
