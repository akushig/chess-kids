# 캐슬링 안내와 조작 개선

빌드 `2026.10.25.7`.

- 왕을 선택하면 합법적인 캐슬링 도착 칸에 성 아이콘과 ‘캐슬링’을 표시한다. 키보드·스크린리더에도 ‘캐슬링 가능’으로 알린다.
- 왕→도착 칸, 왕→해당 룩 두 가지 조작으로 같은 캐슬링을 실행한다. 캐슬링이 막힌 상태에서 룩을 누르면 이유를 알리면서 룩 선택을 허용하므로 일반적인 룩 이동도 계속할 수 있다.
- 왕·룩의 이동 이력, 룩 부재, 현재 체크, 사이의 말, 통과 칸·도착 칸 공격을 구분한다. 위치가 원인이면 해당 칸에 점선 표시와 좌표를 함께 안내한다.
- 왕을 선택했을 때 열 수 있는 ‘캐슬링 안내’는 현재 대국의 양쪽 가능 여부와 조건을 설명한다. 사용자가 닫을 때까지 유지하며, 제한 시간을 사용하는 판에서는 읽는 동안 시간을 멈춘다.
- 설정과 진행 중 도움에 짧은 판에는 캐슬링이 없다고 명시한다. 새 짧은 판의 종류를 세션에 함께 저장한다.
- 설명은 고정 팝업, 표시와 경고는 보드 안의 오버레이를 사용한다. 보드의 위치·크기를 바꾸지 않는다.

앱의 합법수 생성과 설명은 `ChessGame.castlingStatus`에서 같은 판정을 사용한다. 규칙 기준은 [FIDE 3.8.2](https://handbook.fide.com/chapter/e012023)다.

## 검증

`npm test`: 42개 통과. 새 검사에는 각 차단 사유, 왕·룩이 움직였다 돌아온 실제 이동 이력, 룩만 공격받거나 b칸만 공격받는 허용 사례, 양쪽 색·방향·입력 방식과 되돌리기를 포함한다. 기존 독립 합법수 98국면과 perft 8,902개 대조도 통과했다.

`npm run test:browser`: 기존 실제 입력·나이트 투어·저장·오프라인 검사와 보드 고정 156개 시나리오 통과. 새 캐슬링 검사는 360·768·1280px에서 색 2 × 방향 2 × 입력 방식 2의 실행 조합 24개, 차단 이유, 룩 선택, 짧은 판, 도움 팝업, 접근성 이름과 보드 좌표 유지를 확인한다.
