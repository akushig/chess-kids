# 나이트 투어 UX 수정 검수

빌드 `2026.10.25.5` · Playwright / Chromium · 360×780, 768×1024

- 갈림길 알림 스위치가 보드 위에 표시되고 설정을 기억한다.
- 실제 갈림길에서 경고하며, 이동 후보가 남아 있어도 완주가 불가능해진 상태를 구분한다. 탐색 시간 초과를 불가능으로 단정하지 않는다.
- 힌트 첫 사용에 전체 번호 경로가 보인다. ‘다음 한 수’ 선택은 한 칸만 표시하며 게임 상태를 바꾸지 않는다.
- 이동·되돌리기·새로고침 후 힌트가 현재 판과 일치한다. 이전 릴리스의 진행 중인 판도 복원한다.
- 주요 버튼은 세 개이며 모바일 화면 안에 들어간다. 중복 시범 버튼을 제거했다.
- 무작위 시작 설정을 바꿔도 진행 중인 판은 유지된다. ‘다시 하기’는 같은 시작점, ‘설정대로 새 판 시작’은 새 설정을 사용한다.
- 가족 기능과 시작 위치 선택은 접힌 게임 설정 안에 있다. 보드 크기를 기억한다.

전체 자동 검사 **37개 통과**. 기존 모험·체크 도움·저장·가족 공유·오프라인 대전 회귀도 통과했다.
