# 어린이체스

어린이와 가족이 직접 움직이며 배우고 함께 즐기는 정적 웹 앱입니다. 빌드 과정 없이 웹 서버로 실행할 수 있습니다.

## 실행

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 개발 서버에는 Python 3가 필요합니다. 앱 자체에는 서버 API나 런타임 패키지 의존성이 없습니다.

## 현재 경험

- **모험:** 4×4·5×5 룩 입문부터 여섯 말의 이동·잡기·안전 학습. 실패 설명, 한 수 도움, 되돌리기.
- **놀이터:** 나이트 산책·10칸 탐험·5/6/7 크기 완주(갈림길 알림·전체 경로/다음 한 수 힌트), 성 지키기, 왕과 깃발 찾기, 별 수집, 선택형 이동 수 도전, 한 수 발견.
- **대전:** 컴퓨터 5단계·가족 마주 보기·말이 적은 짧은 판. 체크 공격선과 실제 대응 방법, 힌트·시범·되돌리기, 캐슬링·앙파상·승격 선택.
- **이어서 놀기:** 가족 3개 프로필, 콘텐츠 종류별 최근 판, 새로고침 후 복원, 기존 별 보존. 나이트는 번갈아 두거나 같은 시작판을 가족에게 넘길 수 있습니다.
- **기기 지원:** 모바일·태블릿·PC, 키보드 보드 조작, 기물 이름 표시, 동작 줄이기, 선택형 안내 읽기. 음성은 기기의 한국어 음성 합성을 사용합니다.
- **설치·오프라인:** 최초 온라인 로딩 후 앱 자산을 캐시합니다. 실행 중 새 버전이 도착하면 홈에서 저장한 뒤 업데이트할 수 있습니다.

기존 설치본에서 처음 전환할 때는 진행 중인 판을 마친 뒤 앱과 관련 탭을 모두 닫았다 다시 열어 새 버전을 활성화할 수 있습니다.

## 검증

Node 20 이상에서 규칙·콘텐츠·상태 회귀 검사는 별도 패키지 설치 없이 실행됩니다.

```sh
npm test
```

브라우저 통합 검사:

```sh
npm ci
npx playwright install chromium
npm run dev
# 다른 터미널에서
npm run test:browser
```

기존 Chromium을 쓰려면 `CHESS_BROWSER_EXECUTABLE`, 개발 서버 URL을 바꾸려면 `CHESS_TEST_URL`을 지정할 수 있습니다. 검수 이미지·결과는 기본 `/tmp/chess-kids-ui`에 저장되며 `CHESS_QA_OUTPUT`으로 변경할 수 있습니다.

독립 규칙 검증은 [scripts/verify-puzzles.py](scripts/verify-puzzles.py), 결과와 환경은 [QA 기록](docs/qa/README.md)에 설명되어 있습니다.
